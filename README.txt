# BioSustain — Biology Challenge
Web latihan Sustainable Biological System.

## Isi
- Materi ringkas.
- Latihan bebas: 100 soal gabungan.
- Simulasi Penyisihan: 50 soal (20 PG + 30 PG HOTS).
- Simulasi Final: 50 soal (10 PG + 15 PG HOTS + 15 Isian + 10 Isian HOTS).
- Penilaian otomatis, pembahasan, dan kata kunci untuk soal isian.
- Tidak membutuhkan backend/server.

## Cara menjalankan
Buka `index.html` di browser.

## Cara upload ke GitHub Pages
Upload `index.html`, `style.css`, `data.js`, dan `app.js` ke repository GitHub, lalu aktifkan Pages dari Settings → Pages → Deploy from branch.
